# Edunet

# Customer Churn Prediction Project

## Project Goal

This project aims to build and evaluate machine learning models to predict customer churn.

## Files

* `data_loader.py`: Loads the dataset.
* `data_preprocessing.py`: Preprocesses the data for model training.
* `model_training.py`: Trains  models.
* `model_evaluation.py`: Evaluates the trained models.
* `main.py`:  Orchestrates the entire process.
* `README.md`: This file.
* `customer_churn.csv`: (The dataset file)

## How to Run the Project

1.  **Obtain the Dataset:**
    * Download a customer churn dataset and save it as `customer_churn.csv`.
2.  **Install Dependencies:**
    * Install the required Python packages:
        ```bash
        pip install pandas scikit-learn matplotlib seaborn
        ```
3.  **Run the `main.py` script:**
    * Run:
        ```bash
        python main.py
        ```
4.  **View the Output:**
    * The script will print the data exploration, preprocessing information, model training progress, and evaluation metrics.

##  Important Notes

* Ensure that the `customer_churn.csv` file is in the same directory as the Python scripts.
* The actual performance of the models may vary.
